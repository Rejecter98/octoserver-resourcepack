# 레이드 보스 티어표 (보스 제작 기준)

친구들 성장에 맞춰 티어를 하나씩 출시. 한 티어에 약 3주 머무르도록 보상·난이도를 맞춘 표.
**새 레이드 보스는 반드시 이 표의 해당 티어 값으로 설계하고, 설계안에 "티어 / 표 값 / 실제 값"을 같이 보여줄 것.**

## 기준
- 기본 체력 = MythicMobs `Health`. 인원 배율(1명당 +60%, 4명 2.8배)은 OctoRaid 가 자동 적용
- 목표 시간: 일일 보스 = 그 티어 권장 강화로 **솔로 약 4분** / 주간 보스 = **3명이 약 12분**
- 플레이어 실제 초당 피해 = 초당 17.5 × 강화 배율 × 딜 시간 50% (+5 약 10, +10 약 12)
  - 무기 강화 배율(OctoEnhance): +5 1.15, +10 1.40, +15 1.80, +20 2.40, +25 3.40 (사이 값은 표 기준으로 보간)
- 피해 = MythicMobs 원래 피해값 (= `Damage` + 든 무기 공격력, 스킬은 `damage{a=}`).
  네더라이트 + 보호 IV + 해당 강화 방어 기준으로 평타 실제 약 3칸, 큰 패턴 약 7칸이 되도록 잡은 값
  - 표의 피해는 **주간** 기준. **일일 보스는 표의 약 90%**
  - 방어구 강화 감소(OctoEnhance): 부위당 +10 4%, +15 8%, +20 13%, +25 18% (4부위 합 최대 75%)
- 보상 = 그 보스의 강화석: raids.yml `reward.commands` 의 `"enhance stone {player} N"` (+ lore `"강화석 N개"`)

## 티어별 공통 규칙
- 보스 방어력(`Armor`): T1~T3 0~4 / T4~T9 4~6 / T10 이상 6~8 (철퇴 관통이 과하지 않게)
- 페이즈: 일일 50% 1회 / 주간 T4~T9 50% / T10~T13 60%·30% / T14~T15 70%·40%·15%
- 졸개 동시 최대: 일일 2 / 주간 3~4
- 주간 보스는 남은 시간 3분(고티어 5분)부터 광폭화(공격력 증가) 가능
- 티어가 올라갈수록 **새로운 패턴/기믹**으로 차별화 — 체력·피해만 키우지 말 것
- 어그로: 한 명만 계속 맞지 않게 raids.yml `boss.aggro-switch-seconds` 또는
  패턴 끝에 `command{c="raid retarget <caster.uuid>"} @self`
- raid 월드 난이도는 보통(normal) 고정 기준으로 계산
- 체력이 2048 을 넘으므로 spigot.yml `settings.attribute.maxHealth.max: 100000.0` (**모든 적용 체크리스트에 포함**)
- 일일 레이드: `type: daily`, `min-players: 1`, `max-players: 4`, `time-limit: 600`
- 주간 레이드: `type: weekly`, `min-players: 2`, `max-players: 4`, `time-limit: 1200`
- raids.yml 레이드 id: `daily_t4_<테마>`, `weekly_t4_<테마>` 처럼 티어 포함
